# 各平台能抓到的数据清单

> 状态说明：**✅ 已验证**（真机跑过、字段对得上）｜**⚠️ 接口有但未验证**｜**❌ 没有**

---

## 一、三层数据，计费按次

| 层 | 拿到什么 | 计费 |
|---|---|---|
| 列表（搜索 / 主页作品） | 每条内容的概要：id、标题、链接、类型、作者、四个指标、标签、摘要 | 每次 1 单 |
| 详情（单条内容） | 正文、完整指标、作者、标签、发布时间、视频直链、图片 | **每条 1 单** |
| 评论（单条内容） | 评论正文、点赞、作者、回复数 | 每次 1 页 |

**关键**：列表里**没有**视频文件和正文。要视频或全文，必须逐条查详情。
20 条作品的博主 = 20 次详情调用。

| `metrics.commented` | 评论数 |
| `metrics.shared` | 分享 |

| 字段 | 说明 |
|---|---|
| `text` | 完整正文 |
| `video_url` | **视频直链（mp4）** |

| 字段 | 说明 |
|---|---|
| `text` | 评论正文 |

## 五、批量取视频直链 + 下载

两个脚本都在 skill 里，安装后自带：`<skill_root>/scripts/`

### 1. 取直链

```
python "<skill_root>/scripts/video_links.py" --platform <平台> --user <主页链接或ID> --limit 10 --out links.csv
```

| 平台 | `--user` 传什么 |
|---|---|
| 小红书 | 主页链接或 user_id（自动识别） |
| 抖音 | **sec_uid**（不是 uid） |
| TikTok | **secUid** |
| 快手 | userId |

输出 CSV：`platform, item_id, title, note_url, video_url, kind, liked`
`kind` 区分 `mp4` 和 `m4a`（有些平台只给音频流）。

脚本会自己找本地后端（`LINGZAO_LOCAL_DIR` → 包内同级 `lingzao-local` → `~/.lingzao-local`），不用手配路径。

### 2. 下载

```
<skill_root>/scripts/download_videos.ps1 -Csv links.csv -Out "D:\视频\某人"
```

- `-Index "1,3,5-8"` 只下指定几条
- `-DryRun` 只列清单，不动网络
- 已下过的跳过；失败会打印**真实原因**（不是一律"链接过期"）

### 成本提醒

主页 N 条视频 = **N 次详情调用**。默认限 10 条，防止一口气烧掉几十次。
实测阿甜主页 14 条视频：741 MB，用了 14 次详情调用。
