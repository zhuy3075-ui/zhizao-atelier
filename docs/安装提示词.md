# 安装与使用提示词（四个宿主）

给不懂技术的人用：把下面整段**复制粘贴**给对应的 Agent，它自己会装。

---

## 零、先准备两样东西

1. **安装包**：`zhizao-skill-local-1.0.0-local.1.zip`，解压到一个你记得住的地方，比如
   `D:\zhizao`。解压后应该看到 `lingzao`、`lingzao-local`、`install.ps1` 三个东西。
2. **数据源密钥**：形如 `V0R6...` 的一串字符。

### 还没有密钥？先开通（三分钟）

1. 注册：https://dashboard.justoneapi.com/zh/register （有免费调用额度，不用马上付费）
2. 登录控制台拿密钥：https://dashboard.justoneapi.com/zh →「API Token / 访问令牌」→ 整串复制
3. 把密钥保存好，安装时粘进提示词里

官方说明：https://docs.justoneapi.com/zh/usage

> 没有密钥也能装、也能用：选题、标题、内容包、发布检查、复盘这些纯方法论功能不需要它。

各宿主的目录速查：

| 宿主 | skill 目录 | MCP 配置 |
|---|---|---|
| WorkBuddy | `~/.workbuddy/skills` | `~/.workbuddy/mcp.json` |
| Codex | `~/.codex/skills` | `~/.codex/config.toml` |
| Claude Code | `~/.claude/skills` | `~/.claude.json` |
| DeepSeek Harness | `~/.dsh/skills` | `~/.dsh/cordis.patch.yml` |

## 一、WorkBuddy

### 安装提示词（整段复制）

```
帮我安装一个叫 lingzao 的技能包。

安装包在：D:\zhizao

请按顺序做：
1. 确认 D:\zhizao\lingzao\SKILL.md 存在。不存在就停下来问我，不要自己下载别的版本。
2. 把 D:\zhizao\lingzao 整个文件夹复制到 ~/.workbuddy/skills/lingzao。
   如果目标已存在，先改名成 lingzao.bak-今天日期 备份，不要直接覆盖。
3. 复制完告诉我：目标路径、文件总数、SKILL.md 有多少个二级标题。

然后配置数据源（可选，不做也能用纯文字功能）：
4. 读一下 ~/.workbuddy/mcp.json，把下面这个服务加进去（保留原有配置，不要删别的）：
   名字：justoneapi
   类型：stdio
   命令：node
   参数：D:\zhizao\lingzao-local\run-mcp.mjs
   工作目录：D:\zhizao\lingzao-local
5. 我的数据源密钥是：【把密钥粘在这里】。
   请把它写进系统环境变量 JUSTONEAPI_TOKEN，同时写进刚才那个服务配置的 env 里。
6. 最后告诉我：装好了没有、还差什么、下次怎么启动。
```

```
请按「不用联网就能做的」和「需要数据服务的」分开说，各举两个例子。
```

```
cwd = "D:\\zhizao\\zhizao-local"
startup_timeout_sec = 30
tool_timeout_sec = 120

7. 告诉我：配置有没有语法错误、要不要重启 Codex。
```

## 四、DeepSeek Harness

### 安装提示词（整段复制）

```
帮我安装一个叫 lingzao 的技能包。

安装包在：D:\zhizao

请按顺序做：
1. 确认 D:\zhizao\lingzao\SKILL.md 存在，不存在就停下来问我。
2. 把 D:\zhizao\lingzao 复制到 ~/.dsh/skills/lingzao。
   已存在先备份成 lingzao.bak-日期。
3. 复制完刷新一下技能列表，确认 lingzao 出现在可用技能里。
4. 告诉我：路径、文件数、技能有没有被识别到。

然后配置数据源（可选）：
5. 编辑 ~/.dsh/cordis.patch.yml，在已有的 insert 列表里追加一项（不要动别的项）：

  - id: justoneapi-mcp
    name: '@deepseek-ai/dsh-mcp-client'
    config:
      serverName: justoneapi
      transport: stdio
      command: node
      args:
      - D:\zhizao\lingzao-local\run-mcp.mjs
      cwd: D:\zhizao\lingzao-local
      toolCallTimeoutMs: 180000
      failOnStartupError: false

6. 我的数据源密钥是：【把密钥粘在这里】，写进系统环境变量 JUSTONEAPI_TOKEN。
7. 告诉我：要不要重启 Harness 才生效。
```

### 验证提示词

```
用织造说一句话，证明你读到了这个 skill：它和其他写作类 skill 最大的区别是什么？
```

### 日常使用

```
用织造拆一下这个博主的号：<粘贴主页链接>
看人设、内容主线、爆款机制、哪些能学哪些不能学。评论区先不要打开。
```

## 五、不认 skill 的宿主（通用版）

如果上面某个 Agent 说"我没有 skill 目录"，用这段：

```
我没有技能目录，但想让你按一套固定方法帮我做自媒体运营。
请读取这个文件的全部内容，作为你的工作手册：
D:\zhizao\lingzao\SKILL.md

读完先告诉我：
1. 这套方法能做什么、不能做什么
2. 你打算怎么在接下来的对话里用它

以后每次我说「用织造」，你就按这份手册的流程处理，先判断、再决定要不要查数据。
```

## 六、三种常见问题的标准回答

| 现象 | 让用户做什么 |
|---|---|
| Agent 说"没有数据服务" | 双击桌面的「启动织造」，黑窗口别关，再试一次 |
| Agent 说"这个平台不支持" | 正常，不是坏了。让它换平台或改用已给的材料 |
| Agent 直接开始查一堆数据 | 打断它："先别查，先给我筛选标准和数量，我确认后再查" |
